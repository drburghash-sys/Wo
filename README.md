# خطوتي | Khatwati

**كل خطوة تصنع فرقًا** — تطبيق ويب عربي (RTL) بسيط لإنقاص الوزن ومتابعة العادات اليومية، وفق هوية **الزمرد الملكي** وأيقونة **الهدف/مسار التقدم** المعتمدة.

## الوظائف

- إعداد سريع للبالغين وفحص أهلية عام، مع ثلاث خطط: هادئة 12%، متوسطة 19%، مكثفة 24% عند الملاءمة. لا يعتمد على نظام تجويع أو تشخيص.
- تقدير الاحتياج اليومي باستعمال Mifflin–St Jeor وعامل النشاط، مع حدود دنيا محافظة وافتراضات ظاهرة للمستخدم.
- تسجيل الطعام من قائمة أطعمة تقريبية بحصص، أو إدخال السعرات يدويًا.
- تسجيل المشي والرياضة بالدقائق؛ تقدير **الحرق الإضافي** بأسلوب MET. لا تُضاف السعرات المحروقة تلقائيًا إلى ميزانية الطعام.
- الماء: تسجيل سريع 150/250/500 مل، مع هدف قابل للتخصيص.
- الوزن: سجل بتاريخ ورسم بياني مع إعادة حساب السعرات بناءً على الوزن الحالي وإظهار سبب التغيير.
- تذكيرات كل ساعتين أو ثلاث، ساعات نوم صامتة وإيقاف كامل.
- إعداد الوضع الليلي، وتثبيت PWA، وعمل الواجهة دون اتصال بعد أول زيارة (ما دامت الملفات مخزنة مؤقتًا).
- حفظ محلي دون حسابات أو مزامنة، وتصدير واستيراد JSON وحذف البيانات.
- ملف تقويم `.ics` اختياري للتذكير في خلفية النظام عند استيراده إلى تطبيق تقويم يدعم التنبيهات.

## مهمة: حدود الإشعارات

الموقع الثابت على GitHub Pages **لا يستطيع إرسال Push دوريًا إلى جوال مغلق التطبيق** دون خدمة خادم Web Push (اشتراكات Push + مفاتيح VAPID + جدولة إرسال). لذلك التذكيرات المعروضة من المتصفح في هذه النسخة تتطلب بقاء صفحة التطبيق فعّالة. البديل المتاح دون خادم: صدّر ملف التقويم واستورده يدويًا، وتحقق من تفعيل تنبيهات التقويم. مواعيد التقويم ثابتة ولا تعرف مقدار تقدمك اليومي.

على أجهزة iPhone، تتطلب إشعارات Web Push الحقيقية تثبيت تطبيق الويب في الشاشة الرئيسية وإذن المستخدم وخادم إرسال متوافق. هذا **غير منشور** في المشروع الحالي.

## نشر على GitHub Pages

1. أنشئ مستودعًا **عامًا** جديدًا باسم `Wo` في حسابك (`drburghash-sys`). لا تُفعّل README تلقائيًا عند الإنشاء إذا سترفع كامل المشروع دفعة واحدة.
2. ارفع **محتويات** مجلد المشروع إلى جذر المستودع (وليس المجلد المحيط نفسه): `index.html` و`app.js` و`styles.css` و`sw.js` و`manifest.webmanifest` و`privacy.html` و`assets/` و`.nojekyll`.
3. افتح Settings > Pages ثم اختر **Deploy from a branch**، وحدد `main` و`/ (root)` ثم Save.
4. انتظر ظهور رابط النشر من GitHub في صفحة Pages. الرابط المتوقع إذا كانت إعدادات الحساب افتراضية: `https://drburghash-sys.github.io/Wo/`. **لا تعتبره رابطًا يعمل حتى تظهر حالة Published في GitHub.**
5. افتح الموقع على iPhone من Safari ثم مشاركة > إضافة إلى الشاشة الرئيسية، وبعدها شغّل التطبيق من أيقونته.

## تشغيل محلي للفحص

```sh
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000/`. لا تفتح الملف مباشرة `file://` إذا أردت تجربة Service Worker والتثبيت.

## بنية المشروع

- `index.html`: الواجهة العربية
- `styles.css`: تصميم متجاوب ووضع ليلي
- `app.js`: الحسابات والتخزين والرسوم والتذكيرات والتقويم
- `sw.js`: ملفات الواجهة دون اتصال
- `manifest.webmanifest`: تثبيت PWA
- `assets/icon-*.png`: الأيقونة المختارة
- `privacy.html`: الخصوصية وحدود الاستخدام والسلامة

## الخصوصية والطب

لا ترفع نسخ JSON الاحتياطية الشخصية إلى مستودع GitHub عامًا. كل سجلات المستخدمين تُحفظ محليًا في متصفحهم. إذا نُشرت نسخة سحابية في المستقبل فيجب إعادة مراجعة الخصوصية والتنظيم الطبي وقواعد حماية البيانات.

هذه أداة عافية عامة وليس جهازًا طبيًا أو علاجًا للسمنة؛ التصاميم والحسابات الطبية الأولية بحاجة لمراجعة من مختص قبل ترويج الموقع للاستخدام الصحي الواسع.
